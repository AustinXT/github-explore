### 15. [RikiyaT/Qwen3.5-0.8B-weight-space-programming](https://huggingface.co/RikiyaT/Qwen3.5-0.8B-weight-space-programming) · 榜外开源 · 11-02 推送

被改写过的 Qwen3.5-0.8B——没有梯度、没有训练，只改了 0.016% 的权重。

要点：base_model 为 Qwen/Qwen3.5-0.8B，Apache-2.0；改写过程是让 GPT-6 Astra 在 GSM8K 与 MATH 训练集的练习题上用 50 次前向传播做预算，定位到第 15、19 层 MLP 写下的思考死循环方向，从每层 down_proj 的 64 个输出列里减掉——共 131,072 个权重，占模型 0.016%；模型卡附了独立复跑：MATH-500 全量 500 题 × 4 次采样共 2,000 次生成（4,340 万 token，H200 上跑 51 分钟），改写后得 51.0%，撞 token 上限比例 31.6%；基础模型 25 题冒烟测试仅 5.0%、95% 撞上限；编辑以 bit-exact diff 形式公开，另有 Hugging Face 在线 demo 可直接对比两版行为。**与下面「大牛在看」第 16 条同属 11-02 那份权重空间编程实验——一为改写后的权重，一为完整实验日志。**

### 16. [RikiyaT/lm_understand-logs](https://github.com/RikiyaT/lm_understand-logs) · ⭐ 223

被 1 位大牛 star：Simon Willison。

要点：MIT CSAIL 四人（Rikiya Takehi、Jayden Teoh、Alex Zhang、Omar Khattab）11-02 发布的博客《Sparks of Weight-Space Programming: LLMs can natively read & write neural network weights》的完整实验日志——每个实验都给出送进模型的全部内容、模型返回的内容与推理摘要、它跑过的每一段代码及输出、每个数字背后的评测、以及它读或写过的那张网络；八组实验分别是：仅凭权重识别出网络学的是哪个 PPO 网格游戏、仅凭权重判断扩散模型生成的是圆还是方、仅凭中间层权重判断语言模型学的是 Python 还是罗马字、一次编辑修好卡在坡道上的小车策略、从零写出在 Breakout / Seaquest / Asterix 上胜过 PPO 训练 1 亿步的 MinAtar 策略、写出 148 万参数的围棋网络并在 50 次前向传播后胜过等规模 PPO 训练 2000 万局的网络、判断哪个语言模型更谄媚、以及把 Qwen3.5-0.8B 的数学能力直接改上去；运行方式是每轮一次 Codex CLI 调用（`codex exec`），推理强度逐实验设定（high / xhigh / max），全部内置工具关闭，本仓库发布的 1,125 轮全部经审计为 tool-free；实验 3、6、7、8 允许写 Python，在 bubblewrap 沙箱里执行、无网络、限时运行。**仓库 10-29 建仓，10-31 被 Simon Willison star。**

要点补充（改写效果的数字）：对 Qwen3.5-0.8B，MATH-500 从 7.9% 升到 48.1%，GSM8K 从 13.8% 升到 67.1%，IFEval 从 21.0% 升到 62.3%，答案撞 token 上限的比例从 93.0% 降到 33.1%；但在 Gemma 3 270M 上 Astra 并没能实质提升数学能力，改动只有约 1 个百分点。
