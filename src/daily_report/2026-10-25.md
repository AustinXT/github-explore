### 1. [aws/agent-toolkit-for-aws](https://github.com/aws/agent-toolkit-for-aws) · ⭐ 2,998 · Python · 日榜第 3（重返榜 · 上次在榜 06-26）

AWS 官方把 300 多个 AWS 服务接给 AI Agent 的 MCP 服务器与技能包。隔 120 天重返，星数 1,261 → 2,998（+1,737）。

要点：以插件形式打包 MCP Server 配置与 Agent 技能，含 aws-core、aws-agents、aws-data-analytics 等五个插件；通过单一端点 `https://aws-mcp.us-east-1.api.aws/mcp` 访问 300+ AWS 服务，并支持沙箱化 Python 执行；用 IAM 条件键区分「代理操作」与「人工操作」，再结合 CloudWatch 指标与 CloudTrail 日志做审计；技能按需加载，代理只取任务相关指令，覆盖 Bedrock、AgentCore、S3 Tables、Glue、Athena 等服务。本站暂无该仓库的深度报告。

### 2. [Nutlope/hallmark](https://github.com/Nutlope/hallmark) · ⭐ 31,627 · CSS · 日榜第 4（重返榜 · 上次在榜 07-17）

给 Claude Code / Cursor / Codex 用的设计技能，产出避开「AI 味」的网页。隔 99 天重返，三个多月净涨 20,011 星（11,616 → 31,627）。

要点：内置 48 套视觉主题，各自影响字体、配色、材质与组件，并搭配 755 张开放许可照片；分 Floor／Reflex／Finish 三级质量闸，检查对比度、键盘焦点、reduced-motion 与手机端布局；明确点名并拦截常见机器感设计——标题上方的眉标签、字距过大的大写标签、标题里单个彩色词、空壳框架；先设计渲染并审阅 hero 再铺开整页，随后用浏览器在 8 种视口宽度下 lint，改版时保留原有链接与表单行为。
