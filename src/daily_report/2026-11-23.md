### 3. [XingChen-AGI/Xing4.1-Preview](https://huggingface.co/XingChen-AGI/Xing4.1-Preview) · 榜外 · 11-22 开放权重 · Apache 2.0 · 评分 7.1

**285B 总参、17B 激活、原生 1M 上下文——中国电信把星辰的最新一代放了出来。**

要点：HF 模型仓库 **2026-11-22 07:47 UTC 建仓**，Apache 2.0，未做门控，发布当天已收 135 个 like；架构为 **45 层稀疏 MoE（256 个路由专家每 token 激活 8 个 + 1 个共享专家，前 3 层 Dense FFN、后 42 层 MoE）**，注意力走 **MLA + DSA** 组合（与 DeepSeek-V3.2 同源），隐藏维度 4096、128 个注意力头、词表 131,072，**最大上下文 1M**；权重为 **BF16、约 521.4 GiB、261 个 safetensors 分片**，模型卡部署说明写明 **需约 8×80GB GPU（TP=8）**；模型卡另称提供 FP8 量化版本、与 BF16 原版精度差距通常在 1% 左右；由**中国电信人工智能科技有限公司**开发，是 TeleChat 家族最新一代，**全程在完全自研的国产算力栈上端到端训练**，配套技术报告《TeleChat to Xing4: Advancing Frontier Agentic Models on Domestic Chips and Frameworks》（arXiv 2611.22115）已于 **11-17** 挂出；官方 API 走天翼 MaaS、兼容 OpenAI 接口，单请求上限 896K 输入 / 128K 输出，思考模式为开关而非分档；生态已原生打通 **llama.cpp（GGUF，b12174+）、ms-swift v4.6.0+、SGLang 主分支、LLaMA-Factory 主分支**，vLLM 侧有官方 out-of-tree 插件；**基准分数尚未公布**，模型卡说明将随技术报告正式发布。

**它的看点不是「又一个 MoE」，而是权重、推理栈、部署文档同时到位**——llama.cpp 和 SGLang 都是原生支持，不是社区转译。

### 7. [ShinMegamiBoson/lookatmyquant](https://github.com/ShinMegamiBoson/lookatmyquant) · ⭐ 584

被 1 位大牛 star：**欧阳志平**（ouyangzhiping），11-22

**量化编译器：同体积 KL 比 Q4_K_M 低 12 倍，4B 模型压进 1.23GB。**

要点：**2026-10-31 建仓，三周 584★、34 fork，MIT 许可**——README 第一句就是「On Gemma 4 E2B, its GGUF has **12× lower KL than Q4_K_M at the same file size**」；LookAtMyQuant 2 把 **Qwen3.5-4B 压到 1.23GB（2.3 bit/weight）**，540 道精确答案数学题解出 330 道（Prism ML 的 Bonsai 2 Ternary 4B 在 1.20GB 下解出 328，原版 359），与原版的 KL 为 0.45 nats，Bonsai 为 0.59；配方是 **post-training 量化 + trellis 码**，用模型自己解对的数学题做校准、数字 token 加权 10×、按 Fisher 信息逐行分配比特，再做 **4,000 步蒸馏**（每层从原始权重重新量化一次），README 标注 **GPU 成本约 34 美元**；同一配方把 **Qwen3.8-27B 从 53.7GB 压到 7.2GB（2.1 bit/weight）**，数学题 401/540 与原版持平（Unsloth 同尺寸 `UD-IQ2_XXS` 解出 348），HumanEval 73.8% 对 67.1%、MMLU 78.8% 对 75.0%、GSM8K 94.5% 对 92.7%；作者还把 **[thinkingmachines/Inkling-2-Mini](https://huggingface.co/thinkingmachines/Inkling-2-Mini)（26.4B 物理 / 5.4B 激活、3× 循环）从 18.89GB 压到 6 个 MLX 构建（3.85GB ~ 12.76GB）**，其中 12.76GB 版在 GSM8K / HumanEval / 视觉三项共 349 题上与 BF16 教师**逐题打平**，文本权重内存少 29.6%；在 Apple M5 Max 上 12.8GB 版跑到 **2,016 tok/s prefill（T=512）、60.5 tok/s 串行、112.7 tok/s 投机解码**；运行时同时提供 MLX 与 CUDA 双后端，`lamq` 命令可直接起 OpenAI 兼容的 `/v1/chat/completions`。

**它把「量化」从一次性 PTQ 变成了一个带编译器、有校准集、有蒸馏流程的工程**——比特分配按 Fisher 信息走，损失函数是可调的。
