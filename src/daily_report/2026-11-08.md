### 11. [microsoft/agent-framework python-1.25.0](https://github.com/microsoft/agent-framework/releases/tag/python-1.25.0) · 榜外开源 · 11-07 发布

微软 agent 框架的 Python 线，一次性带来 5 个 BREAKING。

要点：移除 Python 3.10 安装资格与过时兼容分支，要求 Python 3.11 以上（Foundry Local 支持 3.11-3.14）；MCP 工具与 prompt 发现被限制在 100 页 / 1,000 项，框架自有的请求超时默认 30 秒，刷新失败时保留完整目录快照——需要更大目录要调 max_discovery_pages / max_discovery_items，或对可信 MCP server 设为 None；工作流 agent 的执行器与 session 被绑定到单一授权 scope，跨 scope 执行在调用模型前即被拒绝，AG-UI 端点里 WorkflowAgent.as_tool() 直接报错；declarative 包改为每次 handler 调用（含 tools/list）新建并关闭协议会话、不再缓存已初始化的 session，这是一条安全修复；OTel span 对齐 OpenTelemetry GenAI 约定，用 `gen_ai.operation.name == "invoke_workflow"` 取代原先对 workflow.run 的精确过滤。另 Foundry Local 迁到 SDK 2.3.1，hyperlight 与 monty 在生成代码恢复前先脱敏主机工具异常详情。
