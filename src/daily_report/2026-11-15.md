## 📌 今日导读

今天的日榜看似大换手，实际是回榜潮：15 席里 AI 相关 11 席，7 个昨日不在榜的项目挤进来、4 个掉榜——但把本地 419 天日榜快照全量核对下来，真正第一次上榜的只有 3 个（AI 项目 2 个），其余全是老面孔重回。而这 6 个入榜的 AI 项目，几乎都在做同一件事：给 Agent 装上外部世界。装前端（AG-UI）、装 Office（Univer）、装交付流程（LoopForge）、装推理后端（TensorFold）、装省 token 的压缩层（caveman）。

第一个看点在协议层。[ag-ui-protocol/ag-ui](https://github.com/ag-ui-protocol/ag-ui) 今日首次登上日榜即第 8，17,248★。它定义约 16 类标准事件，把流式对话、共享状态、工具调用、生成式 UI 与人工审批统一在一套事件协议里——MCP 管 Agent 调工具，A2A 管 Agent 调 Agent，AG-UI 管的是 Agent 怎么跟人说话。

第二个看点在引擎层。[ashhart/TensorFold](https://github.com/ashhart/TensorFold) 在 11-15 01:22（UTC）发布 v1.2.9，一次性补齐 Ollama 兼容接口（`/api/chat`、`/api/generate`、`/api/embed` 等七个端点），并让 Metal 上的并发流共享同一轮解码——M5 Ultra 八流快 2.3–2.5 倍。它同时回到日榜第 9（11-12 曾列第 7），是今天榜内唯一一条「当日发版」。

第三个看点在人这边。榜单换手之外，窗口内唯一的一条大牛新 star 来自 [Simon Willison](https://github.com/lexifina/global-law)（11-14）：`lexifina/global-law` 用 Git 组织各国法条，commit 即一次法律生效，配 `tools/mcp_server.py` 以 MCP 暴露 18 个只读工具。他这次收的不是模型也不是框架，而是一份「法条的可寻址历史」。

### 1. [ag-ui-protocol/ag-ui](https://github.com/ag-ui-protocol/ag-ui) · ⭐ 17,248 · TypeScript · 日榜第 8（首次上榜）· 评分 6.9

用事件协议统一 Agent 与前端交互，补齐 MCP、A2A 之外的一环。

要点：定义约 16 类标准事件，覆盖流式对话、共享状态、工具调用、结构化输出、生成式 UI 与人工审批；中间件支持 SSE、WebSocket、webhook 等传输，可与 LangChain、CrewAI、Google ADK、Mastra、Pydantic AI 等框架对接；提供 Kotlin、Go、Rust、Ruby、Java、C++、Dart、.NET 等 SDK 与 TypeScript 参考实现，MIT 许可，`npx create-ag-ui-app` 可快速起步。

**本地 419 天日榜快照里第一次出现的名字**，而它一出现就是第 8 席、17,248★。它把「人和 Agent 在同一个界面里怎么来回」也当成协议问题来解：生成式 UI 意味着前端不再等一个固定 schema，而是消费事件流；人工审批则是把「人点了同意」也编码成事件，于是审批可以重放、可以审计、可以跨进程传递。MCP 的对接方是工具，A2A 的对接方是另一个 Agent，AG-UI 的对接方是界面——三张网正好拼齐。

本站尚未做过深度分析。

把表格文档编辑能力嵌进自有应用，替代整套第三方 Office 套件。

要点：v1.5.0 新增图表工作表（chart sheet），图表独占标签页、数据留在普通工作表，支持撤销重做与 zoomToFit 自适应；2D 柱状/条形/折线/散点图加逐系列误差棒（固定值、百分比、标准差、标准误与自定义字段），散点图可分设 X/Y 误差棒，另加堆叠与 100% 堆叠折线图；项目分三层——开源 Web SDK 核心（Sheets/Docs/无头计算）加商业化 Server SDK、AI SDK 与 Slides 分发，TypeScript + pnpm/Turbo 单仓库，浏览器、Electron、Node.js 通用，Apache-2.0。

**它和今天另一条新星构成了同一条线索的两端**：AG-UI 规定 Agent 怎么跟界面说话，Univer 给出界面本身的数据与编辑能力。一个定协议，一个把「能编辑、能计算、能协作」的 Office 变成 Agent 可直接驱动的 harness。

### 3. [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman) · ⭐ 119,903 · 日榜第 10（回榜，10-15 曾列第 4）· 评分 6.8

给编码 Agent 装上省 token 的压缩层与路由层，降低调用成本。

### 7. [browser-use/browser-use](https://github.com/browser-use/browser-use) · 榜外发版 · 1.0.5（11-14 08:24 UTC）· 评分 5.9

Agent 浏览器自动化框架 1.0.5 引入自评裁判模型，输出被拦截原因与 gotchas。

要点：1.0.5 发布于 2026-11-14T08:24:22Z，正式版（上一版 1.0.4 于 11-13 发布，已在 11-14 日报收录）；每次运行由用户自己的模型评判，`result.judgement` 返回 success、failure_reason、description、prompt_injection_detected、bot_block_or_captcha_detected 与 gotchas，`judge_context=` 可传自定义判据，`judge=False` 关闭；裁判可见执行 trace、最后若干截图与最终页面，站点拒绝输入、报错、封禁或限流时都会写 gotchas；13 次真实运行各判 3 次，站点有阻碍时 15/15 判定都记录 gotchas（此前为 6/15），干净运行仅 2/24 记录，成功判定率不变。
