### 2. [NVIDIA/OpenShell](https://github.com/NVIDIA/OpenShell) · ⭐ 18,460 · Rust · 日榜第 4 · 重返榜

自 10-02 下榜后再度出现，21 天净增 4,147 星（14,313 → 18,460），是本期涨星最多的仓库。

要点：面向自主 Agent 集群的安全私有运行时。策略写在 policy 里由内核在运行时逐次拦截文件访问、系统调用与网络连接；Agent 永远看不到真实凭据，凭据只被注入到绑定已批准端点的请求上。另有一步较特别——策略变更在生效前先过形式化验证，把「这次放开会不会让 Agent 够到新主机或新 API 方法」标出来，留给人工复核。

> 📖 本站已有深度报告 → https://nightvoyager.top/github-explore/reports/nvidia_openshell/

### 3. [OpenBMB/VoxCPM](https://github.com/OpenBMB/VoxCPM) · ⭐ 40,090 · Python · 日榜第 7 · 重返榜

自 09-14 下榜后再度出现，39 天净增 2,819 星（37,271 → 40,090）。

要点：VoxCPM2 是 2B 参数的 tokenizer-free TTS，绕开离散音频 token，直接在连续表征上做扩散自回归，训练数据超过 200 万小时多语种语音。支持 30 语种合成、48kHz 输出，另有 Voice Design（只用一句自然语言描述造音色，无需参考音频）与可控克隆（短参考片段 + 风格指令调情绪语速），底座是 MiniCPM-4。

> 📖 本站已有深度报告 → https://nightvoyager.top/github-explore/reports/openbmb_voxcpm/

### 4. [SnailSploit/Claude-Red](https://github.com/SnailSploit/Claude-Red) · ⭐ 8,170 · Python · 日榜第 6 · 重返榜

自 09-16 下榜后再度出现，37 天净增 2,576 星（5,594 → 8,170），星数接近翻倍。

### 5. [StartLuxLabs/StartLux-Prism](https://github.com/StartLuxLabs/StartLux-Prism) · ⭐ 55 · Python · 10-22 上线

为 StartLux-Decision v1 / v1.1 AutoThink（4B / 9B / 27B）另写的一套推理引擎：直接吃官方发布的 GGUF 权重，走 TypeSafe 的 `/v1/systemone` API，GPU 从 Ampere 到 Blackwell，单卡或多卡都行。

要点（均为官方 README 自述）：单张 H200 上 int8 对比官方 FP8 引擎（vLLM 0.31），单问快 2.8 倍、三问请求快 5.3 倍，64 客户端吞吐 1.17 倍；8 张 H200 可达 238 req/s，对比官方 BF16 的 138。精度侧，int8 得分 92.94、W4A8 得分 93.07，官方引擎 BF16 为 92.97（StartLux-Decision v1 的七个评测集）。int8 GEMM 在 int32 中精确累加，因此同一问题无论怎么批、几张卡、是否命中前缀缓存，得到的概率逐位一致。视频理解场景里对同一段仓库视频连问 24 题，单请求 0.21 秒，官方引擎 0.72 秒。

### 6. [Tencent-Hunyuan/Hy-Nomas](https://github.com/Tencent-Hunyuan/Hy-Nomas) · ⭐ 37 · Python · 10-21 开源

腾讯混元的可交互视频世界模型，支持自由形式的多轮文本指令与相机轨迹控制，一次生成一段、把同一个「世界」接续下去。

要点：段自回归扩散 Transformer（54 个双流 MMDiT 块）+ Qwen2.5-VL-7B-Instruct 文本编码器 + 相机条件模块 + PixelUMM 视频解码器，段间用常驻 KV cache 承接上下文；文本条件经两层 token refiner 投影进 DiT，相机外参矩阵按四帧一组展成 64 维输入，在每个双流块里与视频 token 做交叉注意力。蒸馏推理配置为 8 步去噪、720×1280、24 FPS；另有单张 RTX 4090 配置（INT8 DiT 权重 + INT8 KV cache + FP8 解码器 + CPU offload）。同期放出 Hy-Nomas-Bench：4 个基准、280 条测试用例，覆盖多轮自由交互、相机导航、文本与相机交替控制、空间记忆。权重与技术报告见 [HF 模型页](https://huggingface.co/tencent/Hy-Nomas)。

### 7. [huggingface/carbon](https://github.com/huggingface/carbon) · ⭐ 232 · Python · Carbon-X 模型 10-21 上线

Hugging Face Bio 开源的 Carbon-X：14.8B 参数的 decoder-only 模型，把 DNA 序列和自然语言放进同一条 token 流里联合训练。

要点：没有独立 DNA 编码器，用混合 tokenizer——文本沿用 Qwen3 的 BPE 词表，DNA 编成 5,515 个专用 token（4,096 个 6-mer、1,364 个补齐 token 及标记位）。模型卡称，在五个 DNA 基准（变异效应预测、序列理解、next-base 预测）上，关掉 thinking 平均 66.7%，比它的底模 Qwen3-14B 高 27 分，在评测过的开源模型里居首；与 GPT-6.1 Sol（67.5%）接近，而单题推理成本约为其 1/1,800。官方估算跑完 ClinVar 里 240 万个意义未明变异约需 300 美元，前沿模型则需 3.2 万至 400 万美元。bf16 权重可放进单张 80GB 显卡，敏感序列不出本地。需 Transformers v5+，可用 vLLM 部署。权重见 [HF 模型页](https://huggingface.co/HuggingFaceBio/Carbon-X)。
