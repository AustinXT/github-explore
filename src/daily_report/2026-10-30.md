### 1. [CopilotKit/OpenBot](https://github.com/CopilotKit/OpenBot) · ⭐ 7,952 · TypeScript · 日榜第 9（新进榜 · 1,037 fork）

给每个 AI 同事配一台自己的电脑：独立浏览器、文件与工具，动作先审批后执行、执行完留审计记录。

要点：TypeScript + Bun 的 monorepo，React/Vite 前端 + Hono API + PostgreSQL（pgvector）+ Docker Compose；每个员工或隔离 Bot 拿到独立的电脑、浏览器 profile、工作区与登录态，动作跑在 Chromium 容器里；**治理是它区别于同类桌面壳的地方**——CEL 表达式策略网关做 fail-closed 判定，把放行、拒绝、失败三类动作全部写进审计轨迹，登录、2FA 这类敏感步骤支持人类接管；可接任意 AG-UI 端点（LangGraph、Mastra、CrewAI、Pydantic AI、Google ADK）；支持个人与部署级技能、带失败次数上限的定时任务，凭据静态加密，支持 Google / Microsoft / Okta / SAML / OIDC 登录，部署可选桌面、Docker 或 Kubernetes + Helm。**MIT 许可，但 README 自述「Beta, under active development」且「A template, not a product」——它是给你 clone 下来改的模板，不是开箱即用的产品。**

### 12. [nvidia/NVIDIA-Nemotron-3.5-Transcribe-30B-A4B](https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Transcribe-30B-A4B) · 外部开源 · 2026-10-28 上线 · OpenMDW License 1.1
