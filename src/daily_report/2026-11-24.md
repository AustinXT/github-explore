要点：HF 模型仓 **2026-11-23 09:00:29 UTC 建仓**，**Apache 2.0、未 gated**，发布当日 127 like；**BF16 主仓之外另开 FP8（blockwise）与 FP8+MXFP4 两个变体**，三仓同为 1M 上下文；架构为 **43 层（1 dense + 42 MoE）**、**512 个 routed 专家 top-10 + 1 个 shared**、每 token 激活 14B，上下文 **1,048,576 token**，由 Base 的 128K 经中训练扩展而来；**精度是训练时就定死的**——路由专家存 MXFP4 并按 **W4A8（4-bit 权重 / 8-bit 激活）做量化感知训练**，训练假量化的粒度、缩放因子与取整规则与推理完全一致，**权重直接按 W4A8 部署，无需额外转换或校准**，KV cache 用 FP8、DSA indexer 用 FP4；43 层里 **37 层用 Heavily Compressed Attention**（每 128 token 历史只缓存 1 条），另 6 层用 DSA 稀疏注意力，投机解码带 DSpark draft head；能力侧在 **30 万个金融、法律类工作区**上训练，持有 **1000 万份参考文件、40+ 种文件类型**；自评 **Terminal-Bench 4.0 46.5、DeepSWE v1.1 71.2、NL2Repo-Bench 64.8、AutomationBench 61.9、CookieBench 88.2、SpreadsheetBench V2 36.4**；推理栈 **day-0**——**vLLM #69425（11-24 02:03 UTC）**更新 ERNIE 配方支持 Preview 版，**SGLang #52626（11-24 04:04 UTC）**同日更新 cookbook。口径差异：README 写 280B 总参，**safetensors 实测统计为 299,559,241,286**（约 2996 亿）。

**权重、量化方案、推理配方三者同时到位**——W4A8 是训练时就对齐的，省掉了社区转译那一层。
