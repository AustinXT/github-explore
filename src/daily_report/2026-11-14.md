### 1. [ggml-org/llama.cpp](https://github.com/ggml-org/llama.cpp) · 榜外发版 · v1.0.0 + ggml v1.0.0 · 11-13 10:20 · 评分 7.6

llama.cpp 与 ggml 在同一天迈过 1.0，公共 C API 第一次有了明确的版本承诺。

要点：llama.h 移除 35 个已废弃函数（`llama_set_warmup`、`--defrag-thold` 等），NextN / 推测解码 API 从 llama-ext.h 提升进 llama.h；新增 OCP FP8 KV cache、宿主内存 MoE 专家缓存（可配 CPU 占比）、外部 PLE 分片加载；新增 Kimi-K3.1-Pro、Ripple、xing4_0 三种文本架构，以及 drama-3 TTS 与 MageVL-Cowork、Kimi-K3.1 视觉支持；llama-server 加固 SSRF、CORS、DNS rebinding 与 MCP 工具取消，新增 `/v1/audio/speech` 端点，web UI 重做并加入聊天群组与 Markdown 编辑器。

**1.0 的分量在承诺里，不在功能清单里**：官方博客写明此后破坏性 public C API 改动一律走 MAJOR，支持 150+ 架构，后端覆盖 NVIDIA、AMD、Qualcomm、Arm、IBM、Intel。本地 AI 生态过去两年的老抱怨是「上游一改 API 我就得跟着改」——这次第一次把它写进了版本号。

### 2. [alibaba/open-code-review](https://github.com/alibaba/open-code-review) · ⭐ 50,420 · Go · 日榜第 1（回榜登顶）· 评分 7.3

阿里内部用了两年的 AI 代码评审引擎，第二次冲上榜首。

要点：混合架构——确定性流水线做硬约束（选文件、打包、规则匹配），LLM Agent 只做软决策（提示词与工具调用）；npm 包 `@alibaba-group/open-code-review`，命令 `ocr`，兼容 OpenAI 与 Anthropic 接口，也能委派给宿主 Agent 用它自己的模型；内置多语言规则集覆盖 NPE、线程安全、XSS、SQL 注入，自建基准 AACR-Bench 已发布到 Hugging Face（含 200 个真实 PR）；当日还发了 v1.13.9——run coverage 记录被排除的文件、零发现 PR 摘要里显示告警、强制按请求声明工具声明。

**它的稀缺性不在模型，而在那套取舍**：自建基准上以约九分之一 token 消耗拿到更高的精确率与 F1，代价是召回率——而且它自己把这个代价写在了明面上。回榜即登顶（10-09 第 5 → 11-13 第 1，44,990★ → 50,420★），两个月再涨 5,430 星。

### 4. [backnotprop/plannotator](https://github.com/backnotprop/plannotator) · ⭐ 10,367 · TypeScript · 日榜第 6（新进榜）· 评分 6.7

把 Agent 的计划评审做成本地浏览器里可以点头、也可以拒绝的工作流。

### 13. [allenai/XYBench](https://github.com/allenai/XYBench) · 外部动态 · 11-13 · 评分 5.5

Ai2 与 CMU、NVIDIA、约翰霍普金斯合作发布的基准，测的是「模型能不能识破用户的前提错误」。

要点：8,115 道题，构造自 1,557 个 Stack Overflow 问题、184 个 Stack Exchange 问题、102 个人工样例与 6,272 个由 WikiHow 指南生成的问题；测三件事——既给字面方案（Y）也给真实目标（X）的方案、答案更强调哪一个、有没有指出误解并把用户拉回 X；在 Stack Overflow 上模型给出字面方案的占比 75–86%，给出真实目标方案的只有 59–71%，主要聚焦真实目标的仅 35–41%；测了 Claude Sonnet 4.6、GPT-5、Gemini 3.1 Pro、Qwen3.5-9B、DeepSeek-V4 Pro，判分模型为 Claude Sonnet 4.5，500 条人工复核与判分模型的一致率 97.5–100%（方案存在性）、84.6–93.3%（误解识别）、74.2–79.8%（强调对象）。

**值得记的是那个「识别—生成差」**：让模型在字面答案和目标导向答案之间二选一时，71–84% 选了目标导向；可让它自由生成，只有 35–41% 真写出来。会「认」不等于会「改」。论文见 [arXiv:2609.06842](https://arxiv.org/abs/2609.06842)，数据集见 [XYBench-dataset](https://huggingface.co/datasets/allenai/XYBench-dataset)。
