要点：核心口径是「Nobody trained these weights; a compiler computed every one.」——作者 dbreunig（Drew Breunig）复用 Qwenputer 的 chipformer 编译器，算出来的不是训练结果而是电路本身；架构为 `Qwen3_5ForCausalLM`，7 层 Gated DeltaNet 承担电路 + 1 层全零 attention（HF cache 需要），hidden size 768，词表 263,808，MLP 宽 9,216，16 个 key head / 32 个 value head；参数 466.6M（bf16 933MB），其中仅 9.3M 非零，压缩后 3.3 MB，编译约 10 秒，内存即模型的 Gated DeltaNet state；速度上 Numba 引擎约 1,650 tokens/s、NumPy 约 210、stock Transformers 约 10，而真实 NES 需约 700,000 tokens/s，整体比真机慢 150–290 倍。**硬限制**：只支持 NROM（iNES mapper 0）与 32KB PRG-ROM，不支持 MMC1/MMC3 换页，非法 opcode 发 HALT，无音频输出，PPU/APU 行为在权重之外；校验方式是参考 CPU 对齐 nestest 3,348 条指令与 py65 的 570 万条指令，精确电路再对齐 283,610 个启动序列位置；MIT（编译器衍生部分另见 LICENSE.chipformer，内置 ROM 各有独立许可）。
