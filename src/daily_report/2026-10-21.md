### 1. [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill) · ⭐33446 · JavaScript · 首次入榜 rank 2 · 🔥 今日必看

Cloudflare 官方发布的 coding-agent skill，把多阶段安全审计拆成可机器校验的流水线——每条发现都必须经过独立 agent 的对抗性复核。

要点：
- 六阶段流程：侦察 → 按覆盖率导向的漏洞猎取 → 独立候选验证 → 结构化发现 → 记录核验 → 报告；核心是**让另一个 agent 来否决自己的结论**，以此压制误报。
- 产出是机器可读的 `architecture.md`、`coverage-ledger.json` 和经 schema 校验的 `findings.json`，每条发现标注 `confirmed` / `needs_validation` / `rejected`，再派生出人读的 `REPORT.md`。
- MIT 协议。3.3 万星的新仓库直接空降第二，说明「让 agent 干安全审计」已经从个人实验变成基础设施需求。

### 2. [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) · ⭐129782 · Python · 首次入榜 rank 7 · 👀 值得关注

把任意代码库连同文档、SQL schema、配置和 PDF 一起转成可查询知识图谱——不建向量库，纯本地确定性解析。

要点：
- 用 tree-sitter 做本地 AST 解析，解析调用、import 等关系并给每条边标注「抽取得出」还是「推断得出」，主张「每条边都可解释」。
- 结果落成 JSON / Markdown / 交互式 HTML，支持作用域查询与路径追踪。
- 目标是 Claude Code、Cursor、Codex、Gemini CLI、Copilot、Aider、OpenCode 等 20+ 编程环境——典型的「反 RAG 拥挤」路线：结构化查询替代 embedding 检索，token 成本更低也更可审计。

> 📖 本站已有深度报告 → [/reports/graphify-labs_graphify/](https://nightvoyager.top/github-explore/reports/graphify-labs_graphify/)
