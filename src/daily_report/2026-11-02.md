### 1. [thedotmack/claude-mem](https://github.com/thedotmack/claude-mem) · ⭐ 108,817 · TypeScript · 日榜第 1（位次持平 · 连续第 3 天登顶 · 单日 +1,509 星 · 9,567 fork）

给编码 Agent 装的跨会话记忆层——连续第三天坐在榜首。

要点：从 Hook 侧外部观察，不改 Claude Code 自身行为，由独立 Observer Agent 把工具调用压成结构化「观察」写入 SQLite；渐进式上下文披露，先给约 800 token 的索引、Agent 自行决定拉哪条详情（约 120 token/条），相对全量注入把上下文从约 35,000 压到约 920；混合检索用 SQLite FTS5（精确）+ Chroma（语义），Chroma 可关闭退回纯 SQLite。Apache-2.0，支持 Claude Code、OpenClaw、Codex、Gemini、Hermes、Copilot、OpenCode 等客户端。**今天位次持平第 1，单日 +1,509 星；30 天窗口在榜 10 次，是升温池里在榜最密的一个，95,342 → 108,817（+13,475 星）。**

### 2. [shiyu-coder/Kronos](https://github.com/shiyu-coder/Kronos) · ⭐ 45,140 · Python · 日榜第 3（时隔 11 天回榜 · 7,504 fork）

把 K 线当语言的金融基础模型，清华研究组出品——今天回榜即第 3。

要点：业内首个开源、专为金融蜡烛图（OHLCV）设计的基础模型，用 BSQ（Binary Spherical Quantization）分词器把连续行情量化成分层 token，自回归 Transformer 在 token 上预训练，像续写文本一样续写 K 线；论文 arXiv:2508.02739 已被 AAAI 2026 录用，合著者含张长水等教授。通用时序基础模型在金融零样本上 R² 为负（连均值都不如），它抢的就是这个空白生态位。MIT 许可；README 主动声明「demo 不是生产交易系统」「微调注释由 AI 生成可能有误」。**30 天窗口在榜 4 次、41,435 → 45,140（+3,705 星），今天回榜即第 3。**

### 10. [SenseNova-Loop-9B-Preview](https://huggingface.co/sensenova/SenseNova-Loop-9B-Preview) · 商汤 · 2026-10-30 发布 · ⭐ 权重在 Hugging Face（927 次下载 / 144 likes）

32 层权重循环出 56 层计算深度——商汤开源的循环多模态模型。

要点：骨干是 32 层多模态解码器，第 4 至 27 层这 24 层共享权重连续跑两遍（写作 B(B(h))），推理时每次前向算 56 层却只存 32 份权重；规模约 9B 总参数、约 14.6B 推理参数，混合线性注意力与全注意力；mHC（流形约束超连接）在循环段维护两条残差流，Sinkhorn 归一化约束混合比例（文档配置用 20 次迭代）；训练序列最长 262,144 token，官方基准覆盖 BIRD-Dev、WorkBuddy Bench、AIDABench、TeamBench、Terminal Bench 2.1、T³-Banking、AutomationBench、RaccoonPPTBench。**Apache-2.0，权重在 Hugging Face、代码在 github.com/OpenSenseNova/SenseNova-Loop；HF 页面 10-28 建仓、10-30 正式发布、11-01 仍在更新，技术报告标注 TBD。**

要点：引擎自带 314 个工具（298 个在引擎内，其余交给 AI 与外部工具链）；流程是先对目标网站 / 应用做真实检测分析，再由编码 Agent 构建新项目并逐项比对差异；构建产物带逐页相似度检查清单，界面提供 Git diff 审阅与运行命令前的人工确认卡，并明确要求 Agent 不得复制 logo、照片或文字，除非用户确认自己拥有。MIT OR Apache-2.0 双许可；跨 macOS / Windows / Linux / FreeBSD 与 Web 端，需要 Rust 1.97+，当前标注 early alpha。**两天 1,154 星。**

### 12. [p-e-w/heretic](https://github.com/p-e-w/heretic) · ⭐ 37,576 · AGPL-3.0 · v2.0.0 发布于 2026-11-01
